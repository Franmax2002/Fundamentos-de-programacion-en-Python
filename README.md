El curso se divide en seis módulos principales, cada uno con un objetivo específico.

**Módulo 1: Introducción a Python**
- Conocí Python como un lenguaje potente, claro y versátil.


- Configuré tu entorno de desarrollo.


- Diferencias entre scripting y programación.


- Escribí y ejecuté mis primeros programas.



**Módulo 2: Conceptos básicos de Python**
- Tipos de datos: enteros, flotantes, cadenas.


- Operadores y variables para manipular datos.


- Flujo de control: condicionales (if-else-elif) y bucles (for, while).


- Capacidad de escribir programas dinámicos que toman decisiones y realizan cálculos.



**Módulo 3: Funciones y módulos**
- Funciones: bloques reutilizables de código que resuelven tareas específicas.


- Módulos: colecciones de funciones y variables que pueden importarse.

- Clases y programación orientada a objetos


- Diferencia entre módulos incorporados y librerías externas.


- Organización del código, reducción de repetición y mejora de eficiencia.



**Módulo 4: Estructuras de datos en Python**
- Listas, tuplas, diccionarios y conjuntos: cómo almacenar y organizar datos.


- Operaciones básicas: acceso (indexación), modificación, iteración.


- Algoritmos básicos: ordenación y búsqueda.


- Elección de la estructura adecuada según la tarea.



**Módulo 5: Manejo de errores y depuración**
- Identificación de errores comunes y excepciones de Python con logging.


- Uso de try-except para manejar errores y evitar que los programas se bloqueen.


- Técnicas y herramientas de depuración para localizar problemas.


- Escritura de código robusto y seguro.



**Módulo 6: Fundamentos de pruebas y control de versiones**
- Pruebas con pytest: escribir pruebas unitarias para verificar que partes del código funcionan correctamente.


- Git: sistema de control de versiones distribuido.


- Rastrear cambios, revertir a versiones anteriores.


- Trabajar de manera colaborativa mediante ramas y fusiones.


- Gestión eficiente del historial del proyecto y colaboración segura.
